# Third-party notices

Bliss Mixer Lab includes code adapted from Craig Drummond's [Bliss Mixer](https://github.com/CDrummond/lms-blissmixer).
Its packages include separately released [bliss-mixer](https://github.com/chrober/bliss-mixer) and [bliss-learner](https://github.com/chrober/bliss-learner) binaries.
The learner describes itself as a port of [bliss-metric-learning](https://github.com/Polochon-street/bliss-metric-learning) by Polochon-street.
The release package contains version-specific dependency inventories, license texts and supplemental upstream notices for both binaries in `third-party-licenses/`. Their native source archives are linked from `SOURCE.md` in the package.
